# ☕ Proyecto Teleférico de Café (CDIO III)

¡Bienvenidos al repositorio oficial del **Proyecto Teleférico de Café**!

Este espacio documenta el desarrollo integral de un sistema electromecánico automatizado diseñado para simular el transporte de café mediante un teleférico a escala. Aquí encontrarás desde la documentación técnica del proyecto hasta el firmware, diseño mecánico, protocolos de prueba y evidencias del desarrollo del prototipo.

---

## 🚀 ¿Qué es el Teleférico de Café?

El **Teleférico de Café** es un sistema automatizado desarrollado con fines académicos e ingenieriles, diseñado para representar el funcionamiento de un teleférico utilizado en zonas cafeteras para el transporte de carga.

El proyecto integra **electrónica, control, mecánica y programación embebida**, permitiendo automatizar el movimiento del sistema, monitorear estados operativos y validar el desempeño estructural y funcional del prototipo.

Este sistema busca simular de manera eficiente el proceso de transporte de café en terrenos montañosos, tomando como referencia aplicaciones reales del contexto cafetero colombiano.

---

## 💡 Motivación y Justificación

El transporte de café en zonas rurales montañosas representa un desafío debido a las condiciones geográficas del terreno. Los teleféricos han sido históricamente una solución eficiente para facilitar el traslado de productos agrícolas entre puntos de difícil acceso.

Este proyecto nace con el propósito de **integrar conocimientos de electrónica, automatización y diseño mecánico** para construir una maqueta funcional que represente este tipo de sistemas de transporte, permitiendo validar conceptos de:

- Sistemas embebidos.
- Control de movimiento.
- Integración electromecánica.
- Automatización de procesos.
- Diseño y validación experimental.

Además, el proyecto fortalece el aprendizaje práctico bajo la metodología **CDIO (Conceive, Design, Implement, Operate)**.

---

## 🎯 Objetivos

### ⚙️ Automatización del Sistema
Desarrollar un sistema capaz de controlar el movimiento del teleférico de forma estable y continua.

### 🖥️ Monitoreo del Estado
Implementar una interfaz visual mediante pantalla LCD para visualizar el estado operativo del sistema.

### 🔋 Integración Electrónica
Diseñar un sistema de alimentación y control estable que garantice el correcto funcionamiento de todos los componentes.

### 🏗️ Diseño Mecánico Funcional
Construir una maqueta resistente y estable que represente adecuadamente un sistema de teleférico cafetero.

---

## 🛠️ Retos Superados y Logros Técnicos

Durante el desarrollo del proyecto se enfrentaron diversos desafíos técnicos relacionados con la integración del hardware y el comportamiento mecánico del sistema:

### ⚡ Integración Electrónica
Se logró una correcta integración entre el microcontrolador, pantalla LCD, sistema de potencia y actuadores, permitiendo una comunicación estable y una operación continua del sistema.

### ⚙️ Control del Movimiento
Se validó el desplazamiento estable del teleférico mediante pruebas funcionales, garantizando un movimiento continuo sin interrupciones ni bloqueos mecánicos.

### 🏗️ Estabilidad Estructural
La maqueta fue diseñada para soportar la operación continua del sistema, manteniendo estabilidad durante las pruebas dinámicas realizadas.

### 📊 Validación Experimental
Se ejecutaron protocolos de prueba documentados para validar:
- Funcionamiento del motor.
- Respuesta del sistema.
- Integridad estructural.
- Correcta visualización en pantalla.
- Estabilidad energética del prototipo.

## 📂 Estructura del Repositorio

El proyecto está organizado en las siguientes carpetas principales para separar la documentación técnica, firmware, mecánica y validaciones del sistema:

### 📁 `0_1_Gestion`
Contiene la documentación administrativa del proyecto, incluyendo cronogramas, matriz de requisitos, costos, listas de materiales (BOM) y planeación de actividades CDIO.

### 📁 `0_2_Firmware`
Código fuente desarrollado para el sistema embebido encargado del control del teleférico, visualización en pantalla LCD y automatización del movimiento.

### 📁 `Dashboard_MAHD`
Contiene la documentación asociada al seguimiento técnico, protocolos de validación y trazabilidad del proyecto.

### 📁 `Definition_Done`
Incluye los criterios de aceptación (**DoD - Definition of Done**) utilizados para validar la finalización de módulos del sistema.

### 📁 `Hardware`
Planos electrónicos, esquemas de conexión y diseño de integración de componentes electrónicos del teleférico.

### 📁 `Mecanica_Sistema`
Contiene las evidencias del desarrollo de la maqueta, diseños estructurales, ensamblaje del sistema y validaciones mecánicas del teleférico.

### 📁 `PROTOCOLO_PRUEBAS`
Procedimientos, metodologías y registros de validación utilizados para comprobar el correcto funcionamiento del sistema electromecánico.

### 📁 `Plantilla_Checklist`
Listas de chequeo empleadas para el control de calidad del hardware, firmware y ensamblaje del prototipo.
