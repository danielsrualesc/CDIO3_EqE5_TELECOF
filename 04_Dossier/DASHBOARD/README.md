## 📋 Descripción General
El **Dashboard MAHD** es la herramienta centralizada de control, seguimiento y validación del proyecto **Teleférico de Café**, diseñada para garantizar la correcta integración entre los sistemas electrónicos, mecánicos y de automatización desarrollados durante el proyecto.

Este tablero permite consolidar la documentación técnica, evidencias experimentales, validaciones de funcionamiento y pruebas realizadas sobre la maqueta y el sistema automatizado del teleférico, asegurando la trazabilidad completa del proceso de diseño e implementación.

## 🎯 Objetivos del Dashboard
1. **Validación Integral:** Garantizar que el sistema del teleférico cumple con los requisitos funcionales, electrónicos y mecánicos establecidos para el proyecto.
2. **Trazabilidad del Desarrollo:** Mantener el historial del diseño de la maqueta, pruebas de funcionamiento, integración de sensores y control del sistema.
3. **Control de Calidad (QA):** Registrar evidencias técnicas y validar el correcto desempeño del teleférico durante las pruebas experimentales.

## 🛠️ Instrucciones de Uso y Mantenimiento
Debido a que el proyecto se encuentra en fase de **Validación y Consolidación**, el dashboard se utilizará como herramienta principal de consulta y trazabilidad.

* Toda evidencia del proceso de diseño, construcción y validación debe registrarse dentro de las hojas correspondientes.
* Las métricas y resultados experimentales del proyecto deben extraerse directamente del dashboard para mantener coherencia documental.
* La carpeta **`mecanica_sistema`** contiene las evidencias visuales del desarrollo de la maqueta y la implementación del sistema del teleférico.
* Se recomienda no modificar fórmulas ni estructuras internas del dashboard para conservar la integridad de la documentación histórica.
